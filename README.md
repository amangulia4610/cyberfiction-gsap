# 🌌 Cyberfiction Clone

A visually immersive cyberpunk-inspired website clone, built as a creative learning project using HTML5 Canvas, Three.js, GSAP, and smooth scrolling libraries.

**🔗 Live Demo:** [cyberfiction.1websol.com](https://cyberfiction.1websol.com)  
**📁 Source Code:** [GitHub Repo](https://github.com/amangulia4610/cyberfiction-gsap)

---

## 📖 Overview

This Cyberfiction clone was created in 2023 as part of my journey into creative web development and interactive UI/UX animation. Inspired by the original [Cyberfiction website](https://cyberfiction.io/) and learning resources from [Sheryians Coding School](https://www.sheryians.com/), the project showcases 3D visuals, canvas animations, glitch effects, and smooth scroll-based transitions.

---

## ✨ Features

- 🎨 Canvas-based Visuals — Background particle animation and shader-like effects  
- 🧠 Three.js Integration — Lightweight 3D environment and interactivity  
- 🎬 GSAP + ScrollTrigger — Scroll animations, pinning sections, reveal transitions  
- 📱 Responsive Design — Works across desktop and mobile devices  
- ⚡ Locomotive Scroll — Smooth, inertia-based scrolling experience  
- 🖥️ Futuristic Cyberpunk UI — Neon colors, glitch text, immersive layout  

---

## 🔧 Tech Stack

- HTML5 — Structure  
- CSS3 — Styling  
- JavaScript (Vanilla) — Logic and interactivity  
- Canvas API — Custom graphic rendering  
- Three.js — 3D environment and elements  
- GSAP & ScrollTrigger — Animation engine  
- Locomotive Scroll — Smooth scrolling framework
